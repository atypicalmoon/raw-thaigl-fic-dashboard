# ReadAWrite 泰百同人数据看板

一个基于 ReadAWrite 公开作品元数据制作的非官方泰百同人数据可视化项目。

正式报告位于 `reports`：`reports/index.html` 为全 CP 报告，`reports/cp.html?cp=CP名称` 为通用单 CP 报告。以 `website` 为根目录启动 Live Server，即可访问主页和全部报告。

看板收录 40+ 对泰百 CP，可按公司、CP、年份和点赞区间进行筛选，用于观察不同 CP 的作品规模、点赞分布和发布趋势。

> 本项目为个人兴趣项目，与 ReadAWrite、艺人、经纪公司及任何官方组织无关。

## 看板内容

- CP 作品规模与头部点赞表现
- 各点赞区间内的 CP 占比
- 全站及单 CP 发文时间趋势
- CP 发文热力图
- 单 CP 数据概览与作品清单
- 公司、CP、年份和点赞区间组合筛选
- 桌面端与移动端响应式布局

看板使用 [D3.js](https://d3js.org/) 完成 CSV 解析、数据统计和图表交互，其余界面使用原生 HTML、CSS 与 JavaScript 实现。

## 数据范围

- 收录至少有 1 章、状态符合规则且发布日期有效的作品。
- CP 通过双方姓名的正序、逆序及部分泰文关键词进行识别。
- 同一链接仅保留一条；同时命中多个 CP 时，优先参考标题关键词，其次参考 Tag 出现顺序。
- 标题或 Tag 命中已整理的 BL 排除词时，作品不进入统计。
- 排除部分以选美 CP、女团 CP 为主的作品。
- 包含部分已经停止合作或不再活动的 CP，仅用于保留历史数据。
- 点赞数和阅读数为抓取时的静态快照，不代表作品的最终数据。
- 本项目不收集或保存作品正文。

## 已知局限

ReadAWrite 的标题、简介和 Tag 可能被作者后续修改，作品也可能更换 CP。关键词检索和自动清洗因此无法完全避免遗漏、误收或错误归属。

发布日期取自作品页面显示的首次发布时间。作者后续修改标题、Tag 或 CP 时，可能产生与 CP 实际活动时间不一致的游离数据。时间趋势更适合用于观察整体变化，不应被视为精确历史记录。

图表颜色仅用于区分数据，不代表官方应援色、排名或任何个人立场。

## 使用说明

欢迎将页面代码用于个人研究、技术交流和非商业改造。

请不要直接搬运或重新发布整份底层数据，也请勿将统计结果用于商业用途或制造不必要的粉圈争议。引用或讨论本项目时，建议保留项目来源及数据口径说明。

## 维护计划

数据不会实时更新。非重大问题将不定期处理，下一次数据更新暂定于年底。

### 报告数据

网页浏览时不会实时联网。剧播节点在生成阶段写入轻量的 `reports/cp-report-data.js`；详细维护说明仅保留在本地文件中。

### 剧名译名优先级

中文剧名优先采用哔哩哔哩使用的译名。该账号未覆盖时，再参考哔哩哔哩其他较常用译名；仍无稳定译名时保留原文剧名。首播日期、项目公布日期和正式预告日期仍需另行核对可靠来源，不能仅凭译名来源推定。

### CP 项目检索顺序

每组 CP 必须依次检索：CP 合称与变体、双方英文及泰文姓名、双方完整姓名与共同参演、已知公司或制作方、剧名原文与中译名。CP 合称没有结果不能直接标记为 `not_found`；只有完成演员本名反查后，才可记录当前核对状态。副 CP 还需从完整演员表反向核对，避免宣传标题未写 CP 合称造成遗漏。
