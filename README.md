# ReadAWrite 泰百同人数据看板

基于 ReadAWrite 公开作品元数据制作的非官方 Thai GL 同人数据可视化项目。

## 页面入口

- `index.html`：主看板，可按公司、CP、年份、点赞和完结状态筛选。
- `reports/index.html`：2026 年 1–7 月阶段性全 CP 报告。
- `reports/cp.html?cp=MilkLove`：自动更新的通用单 CP 报告。

网页只展示最终状态为 `OK` 的作品。点赞和阅读为抓取时点快照；项目不保存作品正文。

## 技术说明

- 原生 HTML、CSS 和 JavaScript。
- D3 使用仓库内固定版本，不依赖外部 CDN。
- 首屏读取压缩摘要；作品标题和作者按 CP 延迟加载。
- 页面代码使用内容哈希缓存，生成数据使用独立数据版本。

本仓库只保存可公开部署的页面和生成数据。抓取、清洗、人工校对、SQLite 数据库与完整维护导出位于独立的私有工具仓库。

## 数据口径

- 至少 1 章、发布日期有效且最终状态为 `OK`。
- 同一链接只保留一条。
- 多 CP 命中优先按标题、Tag 和人工校对确定。
- 所有公司归属来自统一 CP 目录。
- 人工发现的错收作品可通过维护者校对流程修改 CP 或排除。
